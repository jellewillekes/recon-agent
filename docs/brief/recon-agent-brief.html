recon-agent · evaluating AI agents for financial research

It tells you whether an agent change is safe to ship, what a useful answer costs, and whether each claim traces to data the agent really retrieved.

An agent answers analyst questions with tools over SEC EDGAR data. The harness scores the answer and the path taken: the harness is the product, the agent is what it measures. "Reconciliation" here means checking each claim against tool output really returned in that run, and comparing a candidate run with a committed baseline. It is not ledger or bank reconciliation.

Business problem

Analysts want agents that answer questions from filings: revenue, margins, segment figures, risk-factor text. A wrong or unsupported number in research is costly, and a new model, prompt or tool can lower accuracy or raise cost without anyone noticing. recon-agent runs each candidate on fixed benchmark questions and checks it against the baseline before it ships, prices each useful answer, and traces claims to source data. On the current baseline a case scoring at least 0.5 costs about €0.12, judge cost included.

System architecture

Agent setup and verification

Guardrails. Tools return one of five statuses and never raise. Runs have budgets for tool calls, tokens and time. The one write path needs confirmation, and prompt-injection tests check tool data can't trigger it. Eval runs are capped at €1 by default.

The committed baseline: 6 cases answered from fact rows, judged on Haiku 4.5. The verifier checked 16 of its 31 claims, and all 16 were supported. Task completion means a non-empty answer without a runtime error, not a correct one. Multi mode and LangGraph are not yet measured on the current rubric.

Known limits

  • The verifier checks a claim only when it states one figure from the rows it cites. In the baseline 16 of 31 claims qualified. Claims from filing text, or built from three rows such as a free-cash-flow margin, are not checked.
  • The baseline covers 6 cases. The gate treats a change of up to 0.10 in answer score, or one case in completion, as run-to-run noise, so smaller effects can't be confirmed.
  • LangGraph has not been run: it needs a metered API key, and the project runs on a Claude subscription only.
